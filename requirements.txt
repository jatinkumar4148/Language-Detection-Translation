# LinguaDetect AI — dependencies
#
# IMPORTANT: numpy MUST stay below 2.0. The bundled fastText C++ extension
# (as built by the `fasttext` PyPI package) raises
#   "Unable to avoid copy while creating an array as requested"
# on every call to ft_model.predict() when numpy>=2.0 is installed. This
# was verified directly against lid.176.ftz during development — it is a
# hard compatibility ceiling, not a style preference. The original
# notebook's `!pip install "numpy<2.0"` cell already discovered this the
# hard way; this file just makes it permanent and explicit.
numpy<2.0

streamlit>=1.38,<2.0
scikit-learn>=1.3,<1.9       # pipeline was pickled under 1.6.1; 1.3–1.8 load it cleanly (verified)
joblib>=1.3,<2.0
fasttext==0.9.3              # if a prebuilt wheel is not available for your platform,
                              # try `fasttext-wheel==0.9.2` instead (same API)
transformers>=4.30,<5.0
sentencepiece>=0.1.99
torch>=2.0,<3.0              # CPU build is sufficient — see README "Deployment" for the
                              # smaller CPU-only install command
